# ThirdPersonGame - Homework 1

Расширение стандартного Third Person Template на C++.

Реализовано:

- ввод через Enhanced Input;
- спринт с изменением `MaxWalkSpeed`;
- переменная `bIsSprinting`, доступная в Blueprint только для чтения;
- Dynamic Multicast Delegate для взаимодействия;
- вывод сообщения `Interaction triggered!`;
- выносливость на C++: расход во время спринта, восстановление после остановки и автоматическое прекращение спринта при нулевом значении;
- вывод текущей выносливости на экран;
- стандартная анимация бега Third Person Template при увеличенной скорости.

## Управление

- `W`, `A`, `S`, `D` - движение;
- мышь - управление камерой;
- `Space` - прыжок;
- `Left Shift` - спринт;
- `E` - взаимодействие.
